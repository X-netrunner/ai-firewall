Summary of Inter-Process Flow ::
    Packet arrives at wlan0 interface --> triggers XDP hook (ai-firewall-ebpf).
    eBPF checks Ethernet/IPv4 headers, prints packet IP using aya_log_ebpf::info!.
    Log string is written into the kernel eBPF Ring Buffer Map.
    Userspace background task (tokio::task::spawn) wakes up, pulls the string from the ring buffer, and displays it in your console.
