libraries :
    aya::maps::HashMap: A kernel-space map type representing a hash table.
    aya::macros: Macros (like #[map] and #[xdp]) that register variables as eBPF objects in specific ELF sections.

terms :
    1) POD: Plain Old Data. Indicates a struct can be safely copied as raw bytes across memory spaces (userspace/kernel) without pointer errors.
    2) Attribute (#[]): Metadata tags placed above structs or functions to instruct the Rust compiler to handle them in a special way.
    3) dest: The destination port field inside a TCP or UDP packet header.
    4) Macros: Code generation tools in Rust that write repetitive structures automatically.
    5) ELF sections: Segments inside a binary that classify content (like instructions, global variables, or eBPF maps) for the system loader.

explanation:
    1) Structs shared between userspace and kernel-space must implement the `Pod` trait.
    2) Attributes like `#[repr(C)]` ensure that Rust compiles the struct fields in exact C order, avoiding compiler optimization rearrangement.
    3) 'dest' port is a 16-bit big endian integer. We extract it to check which services are being scanned or hit by traffic.
    4) Macros like `#[map]` register our global static variables as eBPF maps.
    5) The eBPF loader looks for specific ELF sections (e.g., '.maps') to initialize the maps on load.

main:
    Up to now, the firewall only logged packets. We need active blocking.
    To do this:
        1) Parse Layer 4 headers: Extract destination ports and protocols (TCP/UDP) to inspect packet details.
        2) Share a Blocklist Map: Create an eBPF HashMap called 'BLOCKLIST' shared between kernel and userspace.

    Sharing memory layout:
        We define the shared types in 'ai-firewall-common/src/lib.rs'.
        - '#![no_std]' is used for compatibility.
        - 'repr(C)' enforces layout compatibility.
        - 'aya::Pod' is implemented on the shared structs so Aya can copy them between memory spaces.

    Updating the kernel logic ('ai-firewall-ebpf/src/main.rs'):
        - Define a static HashMap: 'BLOCKLIST'. Key is source IP (u32), Value is block flag/count (u32).
        - Max entries is set to 1024.
        - Packet inspection:
          - Extract source IP.
          - Query 'BLOCKLIST' map using 'BLOCKLIST.get(&src_ip)'.
          - If the IP exists in the blocklist, log it and return 'xdp_action::XDP_DROP'. This drops the packet at the driver level.
          - Otherwise, parse TCP or UDP headers to read the destination port, and log it using 'info!'.
