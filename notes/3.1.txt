libraries :
    aya::maps::HashMap: The userspace map representation of the eBPF blocklist hash table.
    std::net::Ipv4Addr: Standard library representation of IPv4 addresses.

terms :
    1) Ring Buffer (RingBuf): A modern, lockless circular buffer inside the Linux kernel used to stream packet metadata.
    2) PerfEventArray: An older eBPF mechanism for sending telemetry to userspace (often replaced by RingBuf on modern kernels).
    3) PacketLog: The structural representation of packet events (renamed to PacketEvent in our implementation).

explanation:
    1) Ring buffers allow high-throughput streaming. They are lockless, meaning the kernel writer and userspace reader do not block each other.
    2) PerfEventArray allocates separate memory buffers per CPU core, whereas RingBuf uses a single shared buffer across all cores, reducing memory usage and ensuring ordering.
    3) Sharing a binary struct (PacketEvent) across the map is much more efficient than using strings (e.g. EbpfLogger), which require formatting overhead in the kernel.

main:
    Testing userspace map population:
        - We query the map from userspace: 'ebpf.map_mut("BLOCKLIST").unwrap()'.
        - We convert it into an aya::maps::HashMap object.
        - We block a sample IP (e.g., '8.8.8.8') by converting it to native u32 format and inserting it: 'blocklist.insert(ip_u32, 1, 0)'.
        - This inserts the IP directly into the shared kernel hashmap. If that IP sends traffic, the eBPF kernel program drops it immediately.

    Building a Telemetry System:
        Instead of logging text strings dynamically (which is slow), we want to build a metrics streaming system:
        - Stream structured binary 'PacketEvent' objects containing Source IP, Destination Port, and Protocol.
        - Why do this?
          1. Speed: It is significantly faster and uses less CPU in the kernel.
          2. Analytics: Allows the userspace program to collect structured statistics to feed into threat detection logic or future AI models.
